# Rarèndic

Joc de lèxic en català: cada paraula té una raresa (Habitual, Sorprenent, Excepcional, Rarèndic) i, com més rara, més avança el teu cavall.

Web estàtica: `index.html` amb les imatges (`stage.webp`, `stage2.webp`, `occ2.webp`, `logo.webp`). No cal compilar res.

Les llistes de paraules s'han revisat amb el diccionari ortogràfic de Softcatalà (Jaume Ortolà), doble llicència GPL 2 / LGPL 2.1 (vegeu `LLICENCIA-diccionari.txt`).
